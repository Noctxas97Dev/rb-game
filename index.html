02 / Architecture spotlight

ShintEngine

A modular Unreal Engine C++ gameplay framework.

ShintEngine delivers reusable world interaction, object inspection, inventory, item combination, equipment, batteries, cinematic playback and level-transition systems. Its runtime code lives in one plugin module, with extension points exposed to C++ and Blueprints.

The framework owns its gameplay types and depends on Unreal Engine modules rather than any particular game's module. A host project supplies its character, input assets, visual design, maps and content. ShintEngine is a framework plugin, not a complete game or ready-made playable template.
